# دليل استخدام النظام — للحضانة

> المهمة `1.17`. دليل مختصر يُسلَّم للحضانة التجريبية مع الإطلاق.
> كل ما يحتاجه اليوم الأول، بلا مصطلحات تقنية.

---

## أول يوم — بالترتيب

### 1. الدخول
الرابط + البريد وكلمة المرور تصلك من مزوّد النظام.
أول شيء بعد الدخول: **الإعدادات ← تغيير كلمة المرور**.

### 2. إعدادات الحضانة (الإعدادات)
| الحقل | لماذا يهم |
|---|---|
| اسم المنشأة والشعار | يظهران على كل فاتورة |
| **مواعيد الدوام** | منها يُحسب التأخير — بدونها لا يُحتسب شيء |
| الرسوم الشهرية | القيمة الافتراضية لكل طفل جديد |
| رسوم ساعة التأخير | تُضاف تلقائياً على الفاتورة |
| السجل التجاري والرقم الضريبي | يظهران على الفواتير |

### 3. الفصول ثم المعلمات ثم الأطفال — بهذا الترتيب
الترتيب مقصود: الطفل يُسنَد إلى فصل، والفصل يُسنَد إلى معلمة.
عكسه يعني العودة لتعديل كل شيء.

### 4. حسابات الموظفات
**الإعدادات ← الصلاحيات وحسابات الموظفين**

لكل موظفة **حسابها الخاص**. لا تشاركن حساباً واحداً:
- سجل التغييرات يصبح بلا معنى (كل شيء باسم "المدير")
- خروج موظفة يعني تغيير كلمة المرور على الجميع

**الأدوار الجاهزة:**

| الدور | يرى ويعمل |
|---|---|
| **مدير** | كل شيء |
| **موارد بشرية** | الطاقم وحضورهم — لا يرى الفواتير |
| **معلم/ة** | أطفال فصلها · تسجيل حضورهم · قراءة ملفاتهم |
| **معلم/ة تربية خاصة** | مثل المعلمة + تعديل ملف الطفل |
| **معلم/ة طفولة مبكرة** | مثل المعلمة + الوحدات التعليمية |
| **محاسب** | الفواتير والاشتراكات — **لا يرى** الحالة الصحية للأطفال |

يمكن تعديل أي دور (عدا "مدير") من نفس الصفحة.

## الاستخدام اليومي

### الحضور
- **من النظام**: صفحة الحضور ← تسجيل حضور/انصراف
- **من جهاز عند الباب**: صفحة الحضور ← رابط الحضور العام (QR)

> 🔴 **رابط الحضور العام سرّي.** مَن يملكه يرى قائمة الأطفال.
> لا يُنشر ولا يُصوَّر. عند الشك: بدّليه من نفس الصفحة، ويصبح القديم بلا قيمة فوراً.

### الفواتير
ملف الطفل ← **إصدار فاتورة**. النظام يمنع إصدار فاتورتين لنفس الطفل في نفس الشهر
(إن احتجتِ فاتورة ثانية فعلاً، النظام سيخبرك بالفاتورة الموجودة أولاً).

### التذكيرات
- طفل واحد: ملف الطفل ← إرسال تذكير
- عدة أطفال: صفحة الأطفال ← تحديد ← "إرسال تذكير"

الرسائل تصل **بالبريد الإلكتروني**. تأكدي من صحة بريد كل ولي أمر.

### أولياء الأمور
صفحة أولياء الأمور ← **دعوة**. تصله رسالة، ويدخل برقم جواله ويصله رمز على بريده.

يرى **أطفاله فقط** — لا شيء آخر.

---

## أمور مهمة

### إخراج طفل
ملف الطفل ← **إنهاء التسجيل** ← اختاري السبب (متخرّج / منسحب / منقول) والتاريخ.

> **التاريخ مهم**: منه تُحسب مدة الاحتفاظ بالبيانات (5 سنوات). بعدها تُحذف بيانات الطفل
> الشخصية تلقائياً ويبقى السجل المالي والإحصائي كاملاً — التزاماً بنظام حماية البيانات.

### الحذف بالخطأ
كل حذف يذهب إلى **سلة المحذوفات** ويبقى **30 يوماً**.
الإعدادات ← سلة المحذوفات ← استعادة.
بعد الثلاثين يوماً يصبح نهائياً.

### مَن فعل ماذا
الإعدادات ← **سجل التغييرات**: كل إضافة وتعديل وحذف، بالاسم والوقت.

## أسئلة متكررة

**رسالة "لا تملك صلاحية لهذا الإجراء"**
دور الموظفة لا يشمل هذا الإجراء. المديرة تعدّله من صفحة الصلاحيات.

**لم تصل رسالة لولي الأمر**
1. تحقّقي من البريد في ملف الطفل
2. اطلبي منه فحص مجلد **الرسائل غير المرغوبة** — شائع في البداية
3. الإعدادات ← سجل الإشعارات يبيّن هل أُرسلت أم فشلت

**التأخير لا يُحتسب**
غالباً مواعيد الدوام غير مضبوطة في الإعدادات.

**نسيت كلمة المرور**
صفحة الدخول ← "نسيت كلمة المرور" — يصلك رمز على بريدك.

## عند وجود مشكلة

قبل التواصل، جهّزي:
1. ماذا كنتِ تفعلين بالضبط
2. نص رسالة الخطأ كاملاً
3. الوقت التقريبي
4. هل تتكرر أم حدثت مرة واحدة

هذه الأربعة تختصر وقت الحل إلى النصف.
