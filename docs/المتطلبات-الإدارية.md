## 🔴 اكتشاف مهم: السجل التجاري يحجب أكثر مما ظننّا

الخطة كانت تضع `P1` (D-U-N-S) كأول حاجز، لكن D-U-N-S نفسه يحتاج **سجلاً تجارياً**.
وبمراجعة ما يعتمد عليه السجل التجاري فعلاً، تبيّن أنه لا يحجب المرحلة 3 وحدها:

```
السجل التجاري
   ├── D-U-N-S ──► حساب Apple (Organization) ──► نشر iOS       ◄── المرحلة 3 و 4
   ├── الفوترة النظامية والرقم الضريبي ─────────► بيع تجاري     ◄── M2
   ├── التعاقد مع الحضانات (DPA + الشروط) ─────► بيع تجاري     ◄── M2
   └── حساب Google Play باسم الشركة ───────────► نشر Android   ◄── المرحلة 4
```

> **الخلاصة**: بلا سجل تجاري يمكن إكمال **البناء** و**التشغيل التجريبي** (M1)،
> ولا يمكن **البيع** (M2) ولا **النشر على المتاجر** (M3/M4).

# ٣ · تنبيهات الأخطاء (Sentry) — ✅ مكتمل برمجياً

**يحجب**: M1 · مجاني

بدل الـ Webhook الخام رُكِّبت حزمة **Sentry** نفسها: تجمّع الأخطاء المكرّرة، وتحفظ الأثر (stack trace) والتاريخ، وتُرسل التنبيه.

**المُنجَز في الكود** (لا يلزمكِ شيء منه):
- `@sentry/nextjs` + [`sentry-options.ts`](../src/lib/sentry-options.ts) · [`instrumentation.ts`](../src/instrumentation.ts) · [`instrumentation-client.ts`](../src/instrumentation-client.ts)
- الخصوصية: `sendDefaultPii: false` · بلا تتبّع أداء · **بلا تسجيل جلسات** (كان سيصوّر أسماء الأطفال) · `beforeSend` يحذف الأجسام والكوكيز ويُبقي `id` المستخدم فقط
- المنطقة **الاتحاد الأوروبي** — أسهل في المراجعة النظامية (بند ٧)، ولا يمكن تغييرها لاحقاً
- التقارير تمرّ عبر نطاقنا (`/monitoring`) كي لا تبتلعها مانعات الإعلانات

**الباقي عليكِ** — متغيّرات Vercel ثم إعادة نشر:

- [ ] **٣.١** Vercel ← Settings ← Environment Variables:
  ```
  NEXT_PUBLIC_SENTRY_DSN = https://f3099acd353af57fc4aedda881c92998@o4511847064993792.ingest.de.sentry.io/4511847071350864
  ```
- [ ] **٣.٢** (اختياري، لقراءة الأخطاء بأسماء ملفاتنا لا بكود مضغوط) Sentry ← Settings ← Auth Tokens ← إنشاء توكن، ثم في Vercel:
  ```
  SENTRY_AUTH_TOKEN = ...
  SENTRY_ORG        = <اسم المؤسسة في الرابط>
  SENTRY_PROJECT    = <اسم المشروع>
  ```
- [ ] **٣.٣** أعيدي النشر (المتغيّرات لا تسري على نشر قديم)
- [ ] **٣.٤** Sentry ← Alerts ← تنبيه على بريدك عند أي خطأ جديد

**كيف نتأكد**: بعد النشر، افتحي أي رابط يسبّب خطأ — يظهر في Sentry خلال دقيقة. التنبيهات معطّلة خارج الإنتاج عمداً كي لا تستهلك أخطاء التطوير الحصّة المجانية.
