# تطبيق المدرسة

تطبيق Expo لولي الأمر والمعلم. الخادم يثبت الدور ويحدد البيانات المسموح بها.

## الاتصال المحلي

انسخ `.env.example` إلى `.env.local` داخل مجلد `mobile`، ثم ضع عنوان جهاز التطوير الذي يستطيع الهاتف الوصول إليه:

```env
EXPO_PUBLIC_API_BASE_URL=http://192.168.1.10:3000
```

لا تستخدم `localhost` على هاتف حقيقي؛ فهو يشير إلى الهاتف نفسه. يمكن لمعاينة الويب استخدام `http://127.0.0.1:3000` افتراضيًا.

## التشغيل والتحقق

```bash
npm start
npm run typecheck
npm run lint
npm run doctor
```

التوكنات محفوظة في `expo-secure-store` على iOS وAndroid. معاينة الويب تستخدم ذاكرة الجلسة فقط ولا تحفظ الجلسة بعد إغلاق التبويب.

## الإشعارات

- إشعارات الهاتف تحتاج ربط التطبيق بمشروع EAS ووضع `projectId` في إعدادات Expo، ثم تثبيت نسخة التطوير على جهاز حقيقي.
- الصوت المخصص للإشعارات مؤجل لدفعة مستقلة.
